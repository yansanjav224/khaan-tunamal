# Захиалагчид өгөх гарын авлага

`guide.html` — «Хаан Тунамал Хийц — Вэбсайтын гарын авлага» баримтын эх файл.
Лого нь дотроо base64-ээр шигтгэгдсэн тул ганцаараа бүрэн ажиллана.

## PDF болгож гаргах

Хөтчөөр нээгээд **Print → Save as PDF** гэвэл болно. Тохиргоо:

- Цаас: **A4**
- Хэмжээ: **100%**
- **Background graphics: ON** — эс бөгөөс хавтасны хар дэвсгэр, алтан зураас гарахгүй
- Margins: **Default** (баримт дотроо `@page` тохиргоотой)

Толгой/хөл (хуудасны дугаар) хэрэгтэй бол Chrome-ийн «Headers and footers»-ийг асаана.

## Юуг гараар бөглөх вэ

2-р хуудасны «Нууц үг» мөрүүд **зориудаар хоосон**. Баримтыг и-мэйлээр явуулах
магадлалтай тул нууц үгийг дотор нь бичээгүй — хэвлээд гараар бичих, эсвэл
захиалагчид амаар дамжуулах нь зөв.
