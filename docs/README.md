# Захиалагчид өгөх баримт

- **`onepage.html`** — «Вэбсайтын мэдээлэл», нэг хуудас A4. Захиалагчид өгсөн хувилбар:
  хаяг, нэвтрэх мэдээлэл, админыг хэрхэн ашиглах, санамж.
- `guide.html` — 8 хуудас дэлгэрэнгүй хувилбар. Захиалагч «хэтэрхий их» гэсэн тул
  ашиглаагүй, дараа хэрэг болвол энд байна.

## PDF болгож гаргах

Хөтчөөр нээгээд **Print → Save as PDF**:

- Цаас **A4**, хэмжээ **100%**
- **Background graphics: ON** — эс бөгөөс алтан хайрцаг, зураасууд гарахгүй
- Margins: **Default** (баримт дотроо `@page` тохиргоотой)

## Анхаарах

`onepage.html` дотор **админы нэвтрэх нэр, нууц үг бичигдсэн** байгаа. Энэ файлыг
хэн нэгэнд дамжуулахдаа болгоомжтой байх, нууц үг солигдвол заавал шинэчлэх.
