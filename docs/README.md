# Захиалагчид өгөх баримт

- **`onepage.html`** — «Вэбсайтын мэдээлэл», нэг хуудас A4: хаяг, нэвтрэх
  мэдээлэл, админыг хэрхэн ашиглах, санамж. Захиалагчид өгсөн хувилбар.
- `guide.html` — 8 хуудас дэлгэрэнгүй хувилбар. Захиалагч «хэтэрхий их» гэсэн
  тул ашиглаагүй, дараа хэрэг болвол энд байна.

## ⚠️ Нэвтрэх мэдээлэл энд БАЙХГҮЙ

`onepage.html` дотор `__НЭВТРЭХ_НЭР__`, `__НУУЦ_ҮГ__` гэсэн орлуулга байгаа.
Нууц үгийг git-д хадгалдаггүй. PDF гаргахын өмнө эдгээрийг бодит утгаар нь
солино — бодит утгууд нь техникийн гарын авлагад (репогоос гадна) байгаа.

## PDF болгож гаргах

Хөтчөөр нээгээд **Print → Save as PDF**:

- Цаас **A4**, хэмжээ **100%**
- **Background graphics: ON** — эс бөгөөс алтан хайрцаг, зураасууд гарахгүй
- Margins: **Default** (баримт дотроо `@page` тохиргоотой)
